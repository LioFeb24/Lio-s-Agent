页面内容: 首先，我想告诉你的是，这款叫做大地的香水目前在市面上一共有5个版本，分别是：EDT版（2006年）、香精版（2009年）、雨后大地清新版（2014年）、香根草版（2018年）、以及霜冻大地（2022年），这前三个版本是由爱马仕御用调香师Jean-Claude Ellena调制而成，最后两个版本则是由2016年的接任者Christine Nagel调制而成。
总体而言，爱马仕大地的EDT淡香水版、香精版更加成熟、收敛一些，很适合正式工作场合使用；雨后大地清新版、霜冻大地更加清新，年轻化一些，更适合初入职场的童靴；而至于香根草版，我觉得是介于这两类之间，味道变得更加富有个性一些，也可以买来尝试。
下面我以经典的EDT淡香水版本为参照，从 气味感受、香气结构图、留香时间区别、外观包装区别 这4个角度详细对比、分析并评价了这5款香水。如果你想看自己感兴趣的内容，也都可以点击目录快速直达相应的板块。
我们在这里先看看由Jean-Claude Ellena本人撰写的这本《调香师日记》（对香水感兴趣的朋友可以自行前往阅读）里对大地的描述评价：
在某评测网站上大地甚至打出9.8分的高分，几乎无差评的常年霸占Top1，而当面对Noseknows提问怎么看待大地成为历史上最畅销的香水之一，取得商业上的巨大成功时，他本人则是这样回答：
中间插一段煽情的文字，其实我蛮想把这句话献给在看各位且包括我自己，无论你做文字创作还是视频创作还是其他产品设计等，又或者是这些内容的受众，创作者如果想取得短暂的成功，不可否认的是，他们几乎将大多数钱砸向了市场调查和市场营销上面；而作为受众者，你所能看到百万+点赞、优秀产品等内容其实都是凤毛麟角。我当然也喜欢每个人看到后能点赞、收藏、写下评论以及购买我推荐的香水，但是我却并不会讨好每个人。
看完作者本人以及大量群众的五星评价，我想大地对你的吸引力已经不用我写任何“吹彩虹屁”的评语来鼓励你，你也会毫不犹豫买下这款香水。但很不幸的是，我是个客观公正的评论者，不吹不黑，在你购买之前，我的评论至少可以让更加全面地了解这款香水。
开头的柑橘味道，清凉而短暂，其实很符合成熟男性也同样具有活力的特点，但毕竟随着年纪渐长、经历增多，水果、花香这种流行的馥奇香调逐渐在和你说再见。而到了中后调，香根草的味道开始变得有些重，这时候就开启了温暖、厚重的木质主调。与墨恋纯净的香根草味道不同的是，调香师聪明的使用了安息香脂，它不仅有防挥发，更有抚慰和兴奋的作用。我觉得这样搭配的目的是在寓意男人也是有生命力的动物，也需要被人激发，被人温柔以待，特别是在工作、人生中遇到逆境时，显得尤为重要。
整体个过程下来，香气结构仍旧属于常见的葫芦状。但我认为经典就经典在JCE表达这个香气结构的时候，轮廓足够清晰、重点足够突出，并给予了用香者带有足够提示的想象留白。这应该就是大地在香水圈获得空前成功的重要原因之一。
香精版这款香水虽然是EDT的续作，但是呢，气味上却更像它的长辈。前调的葡萄柚、橙子的清新更加的短暂，它甚至恨不得直接跨过中调，让你立马就看到一颗久经生活磨砺、沉重而内敛的心脏。如果说EDT版还是男人的热烈与成熟，那么香精版则更加的深入到地下，愈加的低调。别人说这款香水三步散也好， 五步散 也罢，这个时候，我认为你无需再像任何不理解你的人解释，你就是那个唯一能支撑自己的那片大地。
与经典版相比，调香师将前中调的清新柑橘调拉长了一些，然后再用木质香轻轻托底，让柑橘调平稳过渡，就像落下的细雨缓慢着地。虽然香调定义为木质馥奇香调，但是比起其他同类型的香水，大地清新版的散发过程更加有点像一位手法老成娴熟的月子阿姨照顾孩子一样，细腻而有章法。我觉得整个过程好像在告诉即将步入社会的年轻男孩子们：你当然可以张扬、有个性，但无论怎样都要有基本的担当责任为底色。
使用这款之前，我在想Nagel会用什么方式继承或者超越JCE的3款经典之作，并让别人记住她。在使用之后我便瞬间明白了。这款香根草版并非真的只是如名字这么直白简单，毫无疑问的，香根草仍然是主角，但闻着闻着会发现葡萄柚、香柠檬等的气息总是围绕着这颗香根草，给人感觉又暖又香。没想到老师傅是注重一步一步过渡丝滑，新人却出其不意的玩多线叙事，竟有点不服输的意味在里面。如果让我选的话，就只为了香根草版的勇气，我也一定要投一票。
我的使用感受：开头是大半个柠檬的清新酸涩、带着一些果香的甜，与杜松子酒的清香味形成了齐头并进的态势。可能是因为与木质主干结合的比较牢固啊，所以，到了中调，基本上就是穿插在木质上的柑橘味、胡椒味逐渐挥发殆尽的过程。而到了尾调处，柑橘味已然离去，木质的主干上仅剩一小段的细木棍、还有几颗胡椒在散发出淡淡的温暖感。
整个散发过程下来，类似于一脚铁锹下去在结霜的地面铲出了一个断面来。上半部分虽然未达到霜冻、或者冷冽的程度，但也还是可以做到让我神清气爽；中间部分柑橘与木质的紧密结合是我最喜欢的部分，也是这款香水的highlight，很有创意；至于底部，则是木质的由强渐弱，也符合调香师Nagel一贯的谨慎风格。
此外，为了方便理解新款霜冻大地的由来，以及大地新老版本的衔接，我在这里根据自己的认知展开讲一讲。在我看来，香根草和霜冻大地是Nagel分别在JCE的EDT版和雨后大地的基础进行创作的。这一点从香气结构上不难发现：
相比雨后大地，霜冻大地在结构上像一把倒放的吉他。它把清新感与木质结合的更加紧密，而木质感本身的散发也变得更谨慎。
而香根草版相比EDT版，也是类似的穿针引线结构，算是Nagel对大地的初次改良。
这5款香水的留香时间，淡香版、馥郁香根草版、霜冻大地版在7-8小时以上，而清新版、香精版的留香时间我记得大概6小时左右。基本都是我早上出门，下午下班回来，气味依然在。
